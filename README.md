# Catch Marrakech – website

Static website for www.catchmarrakech.com, hosted on Vercel.

- `index.html` – the whole site (text, styles, script)
- `*.png`, `og.jpg` – logo, emblem, favicon and social preview image
- `vercel.json` – Vercel settings

Edit `index.html` and commit; Vercel redeploys automatically.
